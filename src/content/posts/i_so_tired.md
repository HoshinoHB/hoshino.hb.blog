# 我好累
一种说不出的累，一种从心里往外涌的累。
 
每天晚上都整晚整晚都睡不着，大脑一直在回想过去和未来的各种事情。
  
抑郁让我总是感觉有无数双眼睛在盯着我，让我很害怕。
  
# 我很抑郁
头晕眼昏、失眠、食欲不振、记忆力减退、注意力不集中、心慌、胸闷、呼吸困难、乏力都在持续透支着我的身体。我也知道每天睡很晚对身体不好，但我就是睡不着，抑郁的情绪让我无法入睡，焦虑的心情让我辗转反侧。
 
活着好痛苦。不知道为什么而活，总觉得自己是多余的；总觉得自己是不值得被爱的；总觉得自己不配拥有幸福的。
 
# 活着好累
不知道为什么要活着，总是头晕头疼；总是心慌手抖；总是失眠睡不着；总是焦虑胡思乱想。
 
# 我好难受
不知道为什么会活着，总觉得活着没意义；总觉得活着好累；总觉得活着都是在为了别人。
 
好想无声地消失，像从来没来过一样。不知道为什么我会活着。
 
我想过很多，但唯一没想过我活着的意义是什么……
