# 前言
- 今天是 2026-04-18
- 今天才发觉，但我却觉得太累了
- 我并不知道还有多久能好，但我并不想继续活下去……
 
# 理由
- 太累了
- 每天都是被迫收包，收的还全是负面的数据包
- 真的累了
- 今天又是体育课强度拉满还被同学又要被老师骂一天
- 好几次我没主动说话还能被他们想起的，今天也不例外
- 刚到第三节课间到教室我就累倒睡着了，但直到午休伟大扫除才被老师叫醒，饭都没吃就要开始工作
- 果然，除了 Work 任何 Reward 都想不到我
- 下午第一节体育也是，下课前我跟别人说过了`帮我带回球拍`，晚自习之前**我自己带的**……
 
## 无活意
- 每他都在想我活着的意义是什么，是……**“为了阿萨拉”**这句口号？是**“与你的日常便是奇迹”这句话的每一天？是为了**“方块人方块魂来世还做方块人”**的这句话给信仰？No.
- 每天都听着**“你是为了班级”“为了家人”“为你自己”**……但这不是他们强加给我的，我真的有能力吗？No……
 
# 结束
- 未经他人苦莫劝他人善，但你诺经我苦也未必有我善……
- 为什么就会这么健康的活着啊？！
- 我想替那些患者去事……
